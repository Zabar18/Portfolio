El Problema

Este fue un proyecto realizado para una cátedra. Consistía en materializar una propuesta web completa donde cualquier aficionado pudiera adquirir escudos de fútbol argentino fabricados artesanalmente en tres tipos de materiales: madera, goma o tela.

Mi Rol

Al llevar adelante el desarrollo en solitario, tuve que hacerme cargo de absolutamente cada uno de los aspectos técnicos y lógicos del proyecto. Esto incluye el análisis inicial, estructuración de directorios, lógica del carrito de compras en JavaScript frontend, maquetación adaptativa, y el diseño y normalización de una base de datos relacional para gestionar los productos.

Proceso de Desarrollo y Planificación

La creación de este sitio web se dio de forma paulatina. En un principio, el avance era muy desorganizado y carecía de estructura: tenía los estilos CSS y los scripts amontonados en la misma carpeta que el archivo HTML.

Poco a poco comprendí la enorme importancia que tiene la organización de carpetas y la planificación arquitectónica antes de escribir código. Al reorganizar todo en carpetas independientes (`Css`, `Scripts`), el proyecto fluyó de forma superior. Logré implementar características avanzadas como filtrado dinámico mediante un buscador de productos, almacenamiento estructurado usando tablas de SQL, persistencia básica de datos y la vista final para concretar los pagos de compras.

Ideación y Pivot Conceptual (UX)

Mi propuesta original de negocio consistía en un gestor bajo demanda para solicitar la producción de escudos personalizados de cualquier club. Sin embargo, analizando el flujo de trabajo, reestructuré la idea para transformarla en un 'escaparate/catálogo' con productos preestablecidos, logrando agilizar y simplificar la compra final.

A nivel de UI (Interfaz de Usuario), inicialmente imaginé un diseño cargado de texturas futbolísticas, campos de fútbol de fondo y pelotas como botones de navegación. Descarté esto al darme cuenta de que saturaba cognitivamente al usuario. Simplifiqué el entorno visual para que la pieza de artesanía física sea el centro absoluto de atención en pantalla.

Solución Final Obtenida

Logré estructurar y publicar un sitio web de e-commerce totalmente funcional, responsivo y adaptado para que cualquier usuario pueda seleccionar, filtrar por material y simular la compra de su escudo de fútbol favorito de forma directa y sin distracciones.
